Part 3 Explanation

The whole idea in one line

Eliminate $[A \mid b]$. If a row of $A$ disappears but its $b$-entry doesn't, the target is unreachable. Otherwise set the free amounts to 0 to get one portfolio, then add every do-nothing trade to get all of them. The rank tells you in advance which of these can happen.

The running example

The four-fund menu from Lesson 7: Nifty $(1, 12, 1)$, Nifty ETF $(1, 12, 1)$, bonds $(1, 7, 0)$, balanced $(1, 9.5, 0.5)$. Rules: budget $B$ (₹ lakh), return $R$ (₹ thousand), exposure $E$. A client asks for a target $b = (B, R, E)$:

$$ \begin{bmatrix} 1 & 1 & 1 & 1 \\ 12 & 12 & 7 & 9.5 \\ 1 & 1 & 0 & 0.5 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{bmatrix} = \begin{bmatrix} B \\ R \\ E \end{bmatrix}. $$

1. Three possible outcomes

The whole idea in one line

A system $Ax = b$ has exactly one solution, no solution, or infinitely many. Never exactly two.

Three 2 × 2 problems with budget and return only show all three.

  1. Nifty + bonds $x + y = 10$, $12x + 7y = 105$. Row 2 $-\ 12 \times$ row 1: $0x + (7 - 12)y = 105 - 120$, so $-5y = -15$, $y = 3$, then $x = 10 - 3 = 7$.

    Outcome Exactly one: ₹7 lakh Nifty, ₹3 lakh bonds.

  2. Twins, ₹120K Nifty and its ETF, target $(10, 120)$. Row 2 $-\ 12 \times$ row 1: $0x + 0y = 120 - 12(10) = 0$. True, and it says nothing.

    Outcome Infinitely many: any split with $x + y = 10$, such as $(10, 0)$, $(4, 6)$, $(-2, 12)$. All earn 12% on ₹10 lakh $=$ ₹120 thousand.

  3. Twins, ₹105K Target $(10, 105)$. Row 2 $-\ 12 \times$ row 1: $0x + 0y = 105 - 120 = -15$. That says $0 = -15$.

    Outcome None. Two copies of a 12% fund can't earn 10.5%.

Why never two? If $x$ and $y$ both work, the trade $y - x$ is a do-nothing trade ($A(y - x) = b - b = 0$), and every multiple of it is too. So $x + t(y - x)$ works for every $t$: one extra solution forces infinitely many.

In one line

A vanished row with a non-zero right side ⇒ none; a vanished row with 0 and a free column ⇒ infinitely many; no free column ⇒ at most one.

2. When is there a solution?

The whole idea in one line

Carry the target along as letters while you eliminate. When a row of $A$ turns into zeros, its right side must be zero too. That gives the exact condition a target must meet.

Method · Elimination on the augmented matrix [A | b]

Put $b$ as an extra column and apply every row operation to it as well. Row operations don't change which $x$ solve the system, so $[A \mid b]$, $[U \mid c]$ and $[R \mid d]$ all have the same solutions.

  1. Row 2 Row 2 $-\ 12 \times$ row 1, the $A$ part as in Lesson 7: $(0, 0, -5, -2.5)$. Right side: $R - 12B$.

    Row 3 Row 3 $-$ row 1: $(0, 0, -1, -0.5)$. Right side: $E - B$.

  2. Row 3 again Row 3 $-\ 0.2 \times$ row 2: the $A$ part becomes $(0, 0, 0, 0)$. Right side: $(E - B) - 0.2(R - 12B) = E - B - 0.2R + 2.4B = E + 1.4B - 0.2R$.

    Tidy Multiply by 5: $5E + 7B - R$. So the third row reads $0 = \tfrac15(7B + 5E - R)$.

$$ [\,U \mid c\,] = \left[\begin{array}{cccc|c} \boxed{1} & 1 & 1 & 1 & B \\ 0 & 0 & \boxed{-5} & -2.5 & R - 12B \\ 0 & 0 & 0 & 0 & \tfrac15(7B + 5E - R) \end{array}\right] $$
Rule · The solvability condition

$Ax = b$ is solvable exactly when every zero row of $U$ has a zero right side. Here: $7B + 5E - R = 0$, that is $R = 7B + 5E$, the very plane $C(A)$ from Lesson 5. The algebra and the picture agree.

Target $(B, R, E)$$7B + 5E - R$Verdict
$(10, 105, 7)$$70 + 35 - 105 = 0$solvable ✓
$(10, 120, 10)$$70 + 50 - 120 = 0$solvable ✓ (all in Nifty)
$(10, 105, 5)$$70 + 25 - 105 = -10$no solution ✗

Why a row vanished. For these funds, exposure is a mix of the other two rules: $E = \tfrac15(R - 7B)$. Whatever combination of rows killed row 3 of $A$ must give 0 on the right as well. MIT's example says the same: row 3 = row 1 + row 2, so the target must have $b_3 = b_1 + b_2$.

In one line

Each vanished row gives one condition on the target; meeting them all is exactly "$b$ is in $C(A)$".

3. The complete solution x = xₚ + xₙ

The whole idea in one line

Find one portfolio by setting the free amounts to zero. Then add any mix of the special solutions (the do-nothing trades from Lesson 7). That's all of them.

Step 1: one answer (the particular solution)

Method · Particular solution x_p

Set every free variable to 0 and back-substitute in $[U \mid c]$ for the pivot variables. (Any one solution would do; this is just the easiest.)

  1. Target $b = (10, 105, 7)$, which passed the test. Right sides: $B = 10$, $R - 12B = 105 - 120 = -15$, last $= 0$ ✓.

    Free = 0 ETF $x_2 = 0$, balanced $x_4 = 0$.

  2. Row 2 $-5x_3 - 2.5(0) = -15 \Rightarrow x_3 = 3$.

    Row 1 $x_1 + 0 + 3 + 0 = 10 \Rightarrow x_1 = 7$.

    So $x_p = (7, 0, 3, 0)$: ₹7 lakh Nifty, ₹3 lakh bonds.

Step 2: add the nullspace

Rule · Complete solution = particular + nullspace

$x = x_p + x_n$ with $x_n$ any vector in $N(A)$: $A(x_p + x_n) = b + 0 = b$. The coefficient of $x_p$ is always exactly 1 (MIT problem 8.1).

$$ x = \begin{bmatrix} 7 \\ 0 \\ 3 \\ 0 \end{bmatrix} + c\begin{bmatrix} -1 \\ 1 \\ 0 \\ 0 \end{bmatrix} + d\begin{bmatrix} -0.5 \\ 0 \\ -0.5 \\ 1 \end{bmatrix} $$

  1. Example $c = 2$, $d = 2$: $(7 - 2 - 1,\ 0 + 2 + 0,\ 3 + 0 - 1,\ 0 + 0 + 2) = (4, 2, 2, 2)$.

    Check Budget $4 + 2 + 2 + 2 = 10$ ✓. Return $48 + 24 + 14 + 19 = 105$ ✓. Exposure $4 + 2 + 0 + 1 = 7$ ✓.

    Picture All solutions form a plane in $\mathbb{R}^4$, parallel to the nullspace plane but shifted to pass through $x_p$. Not a subspace: it misses $0$.

Try it: any target, any free amounts

For the curious: MIT's example in the same steps

$A = \left[\begin{smallmatrix} 1 & 2 & 2 & 2 \\ 2 & 4 & 6 & 8 \\ 3 & 6 & 8 & 10 \end{smallmatrix}\right]$, $b = (1, 5, 6)$: condition $b_3 - b_2 - b_1 = 6 - 5 - 1 = 0$ ✓. With $x_2 = x_4 = 0$: $2x_3 = 5 - 2(1) = 3$, so $x_3 = \tfrac32$; $x_1 + 2(\tfrac32) = 1$, so $x_1 = -2$. Complete solution: $(-2, 0, \tfrac32, 0) + c_1(-2, 1, 0, 0) + c_2(2, 0, -2, 1)$.

In one line

One portfolio (free amounts = 0) + any do-nothing trade = every portfolio that hits the target.

4. Solving with R

The whole idea in one line

Reduce all the way to $[R \mid d]$. Then the particular solution sits in the last column: pivot variables $= d$, free variables $= 0$.

Method · Gauss–Jordan to [R | d]

From $[U \mid c]$: divide each pivot row by its pivot and clear above each pivot, doing the same to the last column. Each non-zero row of $[R \mid d]$ then reads "pivot variable $+$ (free terms) $= d_i$".

  1. Pivot 2 → 1 Row 2 $\div (-5)$: $(0, 0, 1, 0.5 \mid -15 / -5 = 3)$.

    Clear above Row 1 $-$ row 2: $(1 - 0, 1 - 0, 1 - 1, 1 - 0.5 \mid 10 - 3) = (1, 1, 0, 0.5 \mid 7)$.

$$ [\,R \mid d\,] = \left[\begin{array}{cccc|c} \boxed{1} & 1 & 0 & 0.5 & 7 \\ 0 & 0 & \boxed{1} & 0.5 & 3 \\ 0 & 0 & 0 & 0 & 0 \end{array}\right] \qquad \begin{aligned} x_1 + x_2 + 0.5x_4 &= 7 \\ x_3 + 0.5x_4 &= 3 \end{aligned} $$

Free amounts 0: $x_1 = 7$, $x_3 = 3$. That's $x_p = (7, 0, 3, 0)$ with no back substitution, and the special solutions come from $R$'s free columns exactly as in Lesson 7. One matrix gives both halves of the answer.

Check yourself (MIT problem 8.2): reduce $[U \mid c]$ with $U = \left[\begin{smallmatrix} 1 & 2 & 3 \\ 0 & 0 & 4 \end{smallmatrix}\right]$, $c = (5, 8)$, and give the complete solution.

Row 2 $\div 4$: $(0, 0, 1 \mid 2)$. Row 1 $-\ 3 \times$ row 2: $(1, 2, 0 \mid 5 - 6) = (1, 2, 0 \mid -1)$. Free $x_2 = 0$: $x_p = (-1, 0, 2)$. Special ($x_2 = 1$): $(-2, 1, 0)$. Complete: $(-1, 0, 2) + c(-2, 1, 0)$. Check $x_p$ in $U$: $-1 + 0 + 6 = 5$ ✓, $0 + 0 + 8 = 8$ ✓.

In one line

$[R \mid d]$: pivot variables $= d$ when free $= 0$; free columns give the do-nothing trades.

5. The rank decides everything

The whole idea in one line

Compare the rank $r$ with the number of rules $m$ and funds $n$. $r = n$ means no free columns (never more than one answer). $r = m$ means no zero rows (never "no answer").

Rule · The four rank cases

An $m \times n$ matrix of rank $r$ always has $r \le m$ and $r \le n$. Which equalities hold decides the number of solutions.

Case$R$ looks likeSolutions of $Ax = b$With our funds
$r = m = n$ (square, invertible)$I$exactly 1, for every $b$Nifty, bonds, midcap
$r = n < m$ (full column rank, tall)$\left[\begin{smallmatrix} I \\ 0 \end{smallmatrix}\right]$0 or 1Nifty, bonds with 3 rules
$r = m < n$ (full row rank, wide)$[\,I \;\; F\,]$infinitely many, for every $b$Nifty, bonds, midcap, balanced
$r < m$, $r < n$$\left[\begin{smallmatrix} I & F \\ 0 & 0 \end{smallmatrix}\right]$0 or infinitely manyNifty, ETF, bonds, balanced

Case 1: r = m = n: one answer, always

Nifty, bonds, midcap ($3 \times 3$, rank 3; Lesson 6). Target $(10, 111, 7.4)$: the only portfolio is $(5, 3, 2)$. Check: $5 + 3 + 2 = 10$ ✓; $60 + 21 + 30 = 111$ ✓; $5 + 0 + 2.4 = 7.4$ ✓. This is every lesson before this one.

Case 2: r = n < m: at most one

Only Nifty and bonds, but all three rules: $\left[\begin{smallmatrix} 1 & 1 \\ 12 & 7 \\ 1 & 0 \end{smallmatrix}\right]$, rank 2 (both columns pivot). No free column, so never two answers. But a zero row survives, so some targets fail: $(10, 105, 7)$ gives $(7, 3)$; $(10, 105, 5)$ gives nothing (Lesson 5's unreachable target).

Case 3: r = m < n: infinitely many, always

Nifty, bonds, midcap, balanced: rank 3 = number of rules, so no zero row. Every target is reachable, in a line of ways ($n - r = 1$ free column).

  1. Target $(10, 105, 5)$, impossible in case 2.

    Particular Balanced $= 0$, solve with Nifty, bonds, midcap: $x_p = (-1, 6, 5, 0)$. Check: budget $-1 + 6 + 5 = 10$ ✓; return $-12 + 42 + 75 = 105$ ✓; exposure $-1 + 0 + 6 = 5$ ✓.

    Complete $(-1, 6, 5, 0) + t(-0.5, -0.5, 0, 1)$. It needs a short ₹1 lakh of Nifty at $t = 0$; some other $t$ may suit the desk better.

Case 4: r < m and r < n: none or infinitely many

The running example: rank 2, 3 rules, 4 funds. A zero row (so the test $R = 7B + 5E$ can fail) and free columns (so when it passes, there are infinitely many). $(10, 105, 7)$: a plane of answers; $(10, 105, 5)$: none.

Reading the cases as a trader

$r = m$: your products span every target you measure (a "complete" menu for those rules). $r = n$: no product is redundant, so every answer is unique. Real desks usually live in case 3 or 4: more products than risks, and the spare freedom is used to pick the cheapest or most liquid route.

In one line

$r = m$ ⇒ always solvable; $r = n$ ⇒ never more than one answer; both ⇒ exactly one.

Check yourself (MIT recitation): when does $x - 2y - 2z = b_1$, $2x - 5y - 4z = b_2$, $4x - 9y - 8z = b_3$ have a solution, and what is it?

Row 2 $-\ 2 \times$ row 1: $(0, -1, 0 \mid b_2 - 2b_1)$. Row 3 $-\ 4 \times$ row 1: $(0, -1, 0 \mid b_3 - 4b_1)$. Row 3 $-$ row 2: $(0, 0, 0 \mid b_3 - b_2 - 2b_1)$. So it's solvable exactly when $-2b_1 - b_2 + b_3 = 0$. Reducing: $y = 2b_1 - b_2$, $x = 5b_1 - 2b_2 + 2z$. Complete solution: $(5b_1 - 2b_2,\ 2b_1 - b_2,\ 0) + c(2, 0, 1)$. With $b = (1, 1, 3)$: $-2 - 1 + 3 = 0$ ✓, $x_p = (3, 1, 0)$.

6. Summary

Key ideas

  1. $Ax = b$ has one, none or infinitely many solutions, never exactly two. (topic 1)
  2. Eliminate $[A \mid b]$; each zero row of $U$ gives a condition on $b$. All met ⇔ $b \in C(A)$. (topic 2)
  3. $x_p$: free variables $= 0$, back-substitute. Complete solution $x = x_p + x_n$. (topic 3)
  4. $[R \mid d]$ gives $x_p$ directly (pivot variables $= d$) and the special solutions from $F$. (topic 4)
  5. $r = m$: always solvable. $r = n$: at most one solution. $r = m = n$: exactly one. (topic 5)

Words in this lesson

Augmented matrix $[A \mid b]$
$A$ with the target as an extra column, eliminated together.
Solvability condition
A condition on $b$ from a zero row of $U$; all of them hold exactly when $b \in C(A)$.
Particular solution $x_p$
One solution of $Ax = b$; the easy one has all free variables $= 0$.
Complete solution
$x_p + x_n$ for every $x_n$ in $N(A)$.
Full column rank
$r = n$: every column has a pivot; no free variables.
Full row rank
$r = m$: every row has a pivot; no zero rows; every $b$ is reachable.

The other two running examples, one in each of the interesting rank cases.

Example 1: Hedging, every way to hedge

Rows: (market, currency, rates). Hedges: Nifty fut $(1, 0, 0)$, IT fut $(1, 1, 0)$, Bank Nifty fut $(1, 0, 1)$, IT-minus-Nifty spread $(0, 1, 0)$.

2 × 2: Nifty and IT futures (r = m = n)

Market and currency only, target $(10, 3)$: $\left[\begin{smallmatrix} 1 & 1 \\ 0 & 1 \end{smallmatrix}\right]x = (10, 3)$. Row 2: $y = 3$. Row 1: $x + 3 = 10$, $x = 7$. Exactly one hedge: 7 Nifty fut and 3 IT fut.

3 × 2: the same two, now with rates (r = n < m)

$\left[\begin{smallmatrix} 1 & 1 \\ 0 & 1 \\ 0 & 0 \end{smallmatrix}\right]$: the rates row is zero, so the condition is "rates target $= 0$". $(10, 3, 0)$: one hedge, $(7, 3)$. $(10, 3, 2)$: none.

3 × 4: all four hedges (r = m < n)

$$ [\,A \mid b\,] = \left[\begin{array}{cccc|c} 1 & 1 & 1 & 0 & 10 \\ 0 & 1 & 0 & 1 & 3 \\ 0 & 0 & 1 & 0 & 2 \end{array}\right] $$

  1. Rank Already a staircase with pivots in columns 1, 2, 3: $r = 3 = m$. No zero row, so every exposure can be hedged.

    Reduce Row 1 $-$ row 2: $(1, 0, 1, -1 \mid 7)$. Row 1 $-$ row 3: $(1, 0, 0, -1 \mid 5)$. $[R \mid d] = \left[\begin{smallmatrix} 1 & 0 & 0 & -1 & 5 \\ 0 & 1 & 0 & 1 & 3 \\ 0 & 0 & 1 & 0 & 2 \end{smallmatrix}\right]$.

  2. Particular Spread $= 0$: $x_p = (5, 3, 2, 0)$, the Lesson 5 hedge.

    Complete $(5, 3, 2, 0) + t(1, -1, 0, 1)$.

    Check $t = 3$ $(8, 0, 2, 3)$: market $8 + 0 + 2 + 0 = 10$ ✓, currency $0 + 0 + 0 + 3 = 3$ ✓, rates $0 + 0 + 2 + 0 = 2$ ✓. No IT futures needed at all.

Example 2: Lot sizes, every way to build a payoff

Rows: Nifty ends at 19,800 / 20,000 / 20,200 (points per lot). Products: futures $(-200, 0, 200)$, 20,000 call $(0, 0, 200)$, 20,000 put $(200, 0, 0)$, 19,900 call $(0, 100, 300)$.

2 × 2: futures and the 20,000 call, two scenarios (r = m = n)

Target $(-200, 600)$ at 19,800 and 20,200: $-200x = -200$, so $x = 1$; $200(1) + 200y = 600$, so $y = 2$. Exactly one: 1 future + 2 calls.

3 × 4: all four products (r = m < n)

Lesson 7 found rank 3 = number of scenarios, with the put free. So every payoff over these three scenarios can be built, in a line of ways. Client payoff: $b = (-200, 100, 900)$.

  1. Put = 0 19,800 row: $-200x_1 = -200 \Rightarrow x_1 = 1$. 20,000 row: $100x_4 = 100 \Rightarrow x_4 = 1$.

    20,200 row $200(1) + 200x_2 + 300(1) = 900 \Rightarrow 200x_2 = 400 \Rightarrow x_2 = 2$.

    Particular $x_p = (1, 2, 0, 1)$: 1 future, 2 × 20,000 calls, 1 × 19,900 call.

  2. Complete $(1, 2, 0, 1) + t(1, -1, 1, 0)$ (put–call parity added $t$ times).

    Check $t = 2$ $(3, 0, 2, 1)$: 19,800: $-600 + 0 + 400 + 0 = -200$ ✓. 20,000: $0 + 0 + 0 + 100 = 100$ ✓. 20,200: $600 + 0 + 0 + 300 = 900$ ✓.

    Meaning "1 fut + 2 calls + 1 × 19,900 call" and "3 fut + 2 puts + 1 × 19,900 call" are the same payoff. The desk quotes whichever is cheaper today.
