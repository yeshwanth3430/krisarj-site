Part 3 Explanation

The whole lesson in one line

Simplify $[A \mid b]$ to $[R \mid d]$. A zero row with a non-zero end means no answer. Otherwise set the free amounts to 0 and read one answer off $d$. Add any do-nothing trade to get every answer.

1. The question, and the plan

Lesson 7 asked which trades change nothing ($Ax = 0$). Now a client wants something specific: a target $b$. Same menu as Lesson 7:

The menu and the target

Funds: Nifty $(1, 12, 1)$, Nifty ETF $(1, 12, 1)$, bonds $(1, 7, 0)$, balanced $(1, 9.5, 0.5)$. Amounts $x = (x_1, x_2, x_3, x_4)$ in ₹ lakh.

The client wants budget ₹10 lakh, return ₹105 thousand, exposure 7: $b = (10, 105, 7)$.

$$ \begin{bmatrix} 1 & 1 & 1 & 1 \\ 12 & 12 & 7 & 9.5 \\ 1 & 1 & 0 & 0.5 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{bmatrix} = \begin{bmatrix} 10 \\ 105 \\ 7 \end{bmatrix} $$

Three things can happen: the target is impossible, there is exactly one portfolio, or there are infinitely many. The plan finds out which, and gives every portfolio:

StepWhat you doWhat it tells you
1Simplify $[A \mid b]$ to $[R \mid d]$the simplest form of the rules and the target
2Look at the zero rowsis the target possible?
3Set free amounts to 0, read $d$one portfolio that works
4Add the do-nothing tradesevery portfolio that works

2. Step 1: from [A | b] to [R | d]

Method · The augmented matrix [A | b]

Write the target as an extra column on the right. Every row operation is applied to the whole row, including that last entry. Each row still means one rule: "these amounts give this number".

$$ [\,A \mid b\,] = \left[\begin{array}{cccc|c} 1 & 1 & 1 & 1 & 10 \\ 12 & 12 & 7 & 9.5 & 105 \\ 1 & 1 & 0 & 0.5 & 7 \end{array}\right] $$

Now do exactly the five row operations of Lesson 7. The first four columns change exactly as they did there; the only new work is the last column.

  1. Row 2 − 12 × row 1 $(0, 0, -5, -2.5 \mid 105 - 12(10))$ $= (0, 0, -5, -2.5 \mid -15)$.

    Meaning "Return beyond 12%" must be $-15$: the client wants ₹15 thousand less than an all-Nifty ₹10 lakh would earn.

  2. Row 3 − row 1 $(0, 0, -1, -0.5 \mid 7 - 10) = (0, 0, -1, -0.5 \mid -3)$.

  3. Row 3 − 0.2 × row 2 $(0, 0, 0, 0 \mid -3 - 0.2(-15)) = (0, 0, 0, 0 \mid -3 + 3) = (0, 0, 0, 0 \mid 0)$.

  4. Row 2 ÷ (−5) $(0, 0, 1, 0.5 \mid -15 / -5) = (0, 0, 1, 0.5 \mid 3)$.

  5. Row 1 − row 2 $(1, 1, 0, 0.5 \mid 10 - 3) = (1, 1, 0, 0.5 \mid 7)$.

Method · Reduce [A | b] to [R | d]

Clear below the pivots ($A \to U$), then make each pivot 1 and clear above it ($U \to R$), all on the full rows. The left part becomes $R$ (the same $R$ as for $Ax = 0$); the last column becomes $d$.

$$ [\,R \mid d\,] = \left[\begin{array}{cccc|c} \boxed{1} & 1 & 0 & 0.5 & 7 \\ 0 & 0 & \boxed{1} & 0.5 & 3 \\ 0 & 0 & 0 & 0 & 0 \end{array}\right] \qquad \begin{aligned} \text{row 1: } & x_1 + x_2 + 0.5x_4 = 7 \\ \text{row 2: } & x_3 + 0.5x_4 = 3 \\ \text{row 3: } & 0 = 0 \end{aligned} $$

Everything we need is in this one matrix.

In one line

Same row operations as Lesson 7, carried through the target column too.

3. Step 2: check the zero rows

Row 3 of $R$ is all zeros. It reads $0x_1 + 0x_2 + 0x_3 + 0x_4 = d_3$. Whatever amounts you choose, the left side is 0, so this row only works if $d_3 = 0$.

Rule · The zero-row test

Look at every all-zero row of $R$. If its last entry is 0, it's fine ("$0 = 0$"). If its last entry is not 0, it says "$0 =$ something", which no trade can do: the target is impossible. If there are no zero rows at all, every target passes.

Target $(B, R, E)$Last entry of row 3 after Step 1Verdict
$(10, 105, 7)$$(7 - 10) - 0.2(105 - 120) = -3 + 3 = 0$possible ✓
$(10, 105, 5)$$(5 - 10) - 0.2(105 - 120) = -5 + 3 = -2$row 3 says $0 = -2$: impossible ✗

Why $(10, 105, 5)$ fails, in plain words. The zero row came from exposure: for these funds, exposure is already decided once you fix budget and return. ₹10 lakh earning ₹105 thousand forces exposure 7, so asking for 5 is asking for two different things at once.

For the curious: the test for any target

With letters $b = (B, R, E)$ the same steps leave row 3 with last entry $(E - B) - 0.2(R - 12B) = \tfrac15(7B + 5E - R)$. So a target is possible exactly when $R = 7B + 5E$: the plane $C(A)$ from Lesson 5. For $(10, 105, 7)$: $70 + 35 = 105$ ✓. For $(10, 105, 5)$: $70 + 25 = 95 \ne 105$ ✗.

In one line

A zero row ending in 0 is harmless; a zero row ending in anything else means no portfolio exists.

4. Step 3: one answer

The target $(10, 105, 7)$ passed. To get one portfolio, make the simplest choice: put 0 in every free fund (ETF $x_2 = 0$, balanced $x_4 = 0$). Then each row of $[R \mid d]$ just reads off a pivot amount:

  1. Row 1 $x_1 + 0 + 0.5(0) = 7 \Rightarrow x_1 = 7$.

    Row 2 $x_3 + 0.5(0) = 3 \Rightarrow x_3 = 3$.

    Answer $x_p = (7, 0, 3, 0)$: ₹7 lakh Nifty, ₹3 lakh bonds.

  2. Check in A Budget $7 + 0 + 3 + 0 = 10$ ✓. Return $84 + 0 + 21 + 0 = 105$ ✓. Exposure $7 + 0 + 0 + 0 = 7$ ✓.

Method · Particular solution x_p

Free amounts $= 0$. Then each pivot amount equals the last entry $d$ of its row. No solving needed.

In one line

Zero in the free funds, $d$ in the pivot funds: one portfolio, read straight off.

5. Step 4: every answer

Zero in the free funds was just one choice. Like in Lesson 7, you can pick any free amounts and $[R \mid d]$ gives the pivot amounts.

  1. You pick ETF $x_2 = 3$, balanced $x_4 = 2$.

    Row 2 $x_3 + 0.5(2) = 3 \Rightarrow x_3 = 2$.

    Row 1 $x_1 + 3 + 0.5(2) = 7 \Rightarrow x_1 = 3$.

  2. Portfolio $(3, 3, 2, 2)$: ₹3L Nifty, ₹3L ETF, ₹2L bonds, ₹2L balanced.

    Check in A Budget $3 + 3 + 2 + 2 = 10$ ✓. Return $36 + 36 + 14 + 19 = 105$ ✓. Exposure $3 + 3 + 0 + 1 = 7$ ✓.

In general, with ETF $= c$ and balanced $= d$, the rows give Nifty $= 7 - c - 0.5d$ and bonds $= 3 - 0.5d$. Split that up:

$$ \begin{bmatrix} 7 - c - 0.5d \\ c \\ 3 - 0.5d \\ d \end{bmatrix} = \underbrace{\begin{bmatrix} 7 \\ 0 \\ 3 \\ 0 \end{bmatrix}}_{x_p \text{ (Step 3)}} + \underbrace{c\begin{bmatrix} -1 \\ 1 \\ 0 \\ 0 \end{bmatrix} + d\begin{bmatrix} -0.5 \\ 0 \\ -0.5 \\ 1 \end{bmatrix}}_{\text{do-nothing trades (Lesson 7)}} $$
Rule · Every answer = one answer + a do-nothing trade

$x = x_p + x_n$, with $x_n$ any do-nothing trade. It works because $A(x_p + x_n) = b + 0 = b$. And there's nothing else: if $x$ is any answer, then $x - x_p$ changes nothing ($b - b = 0$), so it's a do-nothing trade.

In money terms: once you have one portfolio that hits the target, you can swap Nifty for the ETF, or build balanced out of Nifty and bonds, as much as you like. The target stays hit. That's why there are infinitely many answers here.

Try it: any target, any free amounts

In one line

Pick any free amounts, read the pivot amounts off $[R \mid d]$: that's every answer, and it equals one answer plus a do-nothing trade.

6. The same four steps on smaller menus

Same steps, smaller matrices. These show all three outcomes.

2 × 2: Nifty and bonds, target (10, 105): exactly one answer

  1. Step 1 $\left[\begin{smallmatrix} 1 & 1 & | & 10 \\ 12 & 7 & | & 105 \end{smallmatrix}\right]$. Row 2 $-\ 12 \times$ row 1: $(0, -5 \mid 105 - 120 = -15)$. Row 2 $\div (-5)$: $(0, 1 \mid 3)$. Row 1 $-$ row 2: $(1, 0 \mid 7)$.

    Step 2 No zero rows: possible.

    Steps 3–4 No free columns, so nothing to choose: $x = (7, 3)$ is the only answer.

2 × 2: Nifty and its twin, target (10, 120): infinitely many

  1. Step 1 $\left[\begin{smallmatrix} 1 & 1 & | & 10 \\ 12 & 12 & | & 120 \end{smallmatrix}\right]$. Row 2 $-\ 12 \times$ row 1: $(0, 0 \mid 120 - 120 = 0)$.

    Step 2 Zero row ends in 0: possible.

    Step 3 ETF free $= 0$: Nifty $= 10$, so $x_p = (10, 0)$.

    Step 4 $x = (10, 0) + c(-1, 1)$: any split of ₹10 lakh between the twins.

2 × 2: Nifty and its twin, target (10, 105): no answer

  1. Step 1 Row 2 $-\ 12 \times$ row 1: $(0, 0 \mid 105 - 120 = -15)$.

    Step 2 The zero row says $0 = -15$: impossible. Two copies of a 12% fund can't earn 10.5%.

3 × 3: Nifty, bonds, midcap, target (10, 111, 7.4): exactly one answer

  1. Clear below Row 2 $-\ 12 \times$ row 1: $(0, -5, 3 \mid 111 - 120 = -9)$. Row 3 $-$ row 1: $(0, -1, 0.2 \mid 7.4 - 10 = -2.6)$. Row 3 $-\ 0.2 \times$ row 2: $(0, 0, -0.4 \mid -2.6 + 1.8 = -0.8)$.

    Clear above Row 3 $\div (-0.4)$: $(0, 0, 1 \mid 2)$. Row 2 $-\ 3 \times$ row 3: $(0, -5, 0 \mid -9 - 6 = -15)$, then $\div (-5)$: $(0, 1, 0 \mid 3)$. Row 1 $-$ row 2 $-$ row 3: $(1, 0, 0 \mid 10 - 3 - 2 = 5)$.

    Read $R = I$: no zero rows, no free columns. The only answer is $(5, 3, 2)$. Check: $5 + 3 + 2 = 10$ ✓, $60 + 21 + 30 = 111$ ✓, $5 + 0 + 2.4 = 7.4$ ✓.

3 × 3: Nifty, bonds, balanced, target (10, 105, 7): infinitely many

  1. Step 1 As in topic 2 without the ETF column: $[R \mid d] = \left[\begin{smallmatrix} 1 & 0 & 0.5 & | & 7 \\ 0 & 1 & 0.5 & | & 3 \\ 0 & 0 & 0 & | & 0 \end{smallmatrix}\right]$.

    Step 2 Zero row ends in 0: possible.

    Steps 3–4 Balanced free $= 0$: $x_p = (7, 3, 0)$. Every answer: $(7, 3, 0) + t(-0.5, -0.5, 1)$, as in Lesson 6.

Check yourself (MIT lecture): solve $\left[\begin{smallmatrix} 1 & 2 & 2 & 2 \\ 2 & 4 & 6 & 8 \\ 3 & 6 & 8 & 10 \end{smallmatrix}\right]x = (1, 5, 6)$.

Step 1: row 2 $-\ 2 \times$ row 1 $= (0, 0, 2, 4 \mid 3)$; row 3 $-\ 3 \times$ row 1 $= (0, 0, 2, 4 \mid 3)$; row 3 $-$ row 2 $= (0, 0, 0, 0 \mid 0)$; row 2 $\div 2 = (0, 0, 1, 2 \mid \tfrac32)$; row 1 $-\ 2 \times$ row 2 $= (1, 2, 0, -2 \mid -2)$. Step 2: zero row ends in 0 ✓. Step 3: $x_2 = x_4 = 0$ gives $x_p = (-2, 0, \tfrac32, 0)$. Step 4: add $c_1(-2, 1, 0, 0) + c_2(2, 0, -2, 1)$.

Check yourself (MIT recitation): when can $x - 2y - 2z = b_1$, $2x - 5y - 4z = b_2$, $4x - 9y - 8z = b_3$ be solved?

Row 2 $-\ 2 \times$ row 1: $(0, -1, 0 \mid b_2 - 2b_1)$. Row 3 $-\ 4 \times$ row 1: $(0, -1, 0 \mid b_3 - 4b_1)$. Row 3 $-$ row 2: $(0, 0, 0 \mid b_3 - b_2 - 2b_1)$. Zero-row test: solvable exactly when $b_3 - b_2 - 2b_1 = 0$. Finishing: $y = 2b_1 - b_2$, $x = 5b_1 - 2b_2 + 2z$, so every answer is $(5b_1 - 2b_2,\ 2b_1 - b_2,\ 0) + c(2, 0, 1)$. For $b = (1, 1, 3)$: $3 - 1 - 2 = 0$ ✓ and $x_p = (3, 1, 0)$.

In one line

Bad zero row ⇒ none. Otherwise: free column ⇒ infinitely many; no free column ⇒ exactly one.

7. How many answers? The rank tells you

Topic 6 showed the outcome depends on two things in $R$: zero rows and free columns. Both are counted by the rank $r$ (the number of pivots), for a menu with $m$ rules and $n$ funds:

  • Zero rows $= m - r$. If $r = m$ there are none, so every target is possible.
  • Free columns $= n - r$. If $r = n$ there are none, so there is never more than one answer.
Rule · The four rank cases

So the rank tells you what can happen before you even look at the target.

RankZero rows?Free columns?AnswersMenu
$r = m = n$nonoexactly 1, for every targetNifty, bonds, midcap
$r = n < m$yesno0 or 1Nifty, bonds (3 rules)
$r = m < n$noyesinfinitely many, for every targetNifty, bonds, midcap, balanced
$r < m$, $r < n$yesyes0 or infinitely manyNifty, ETF, bonds, balanced

An example of the third row. Nifty, bonds, midcap, balanced has rank 3 = 3 rules: no zero rows. So even $(10, 105, 5)$, impossible for our main menu, is possible here, for example $(-1, 6, 5, 0)$ (short ₹1 lakh Nifty, ₹6 lakh bonds, ₹5 lakh midcap). Check: $-1 + 6 + 5 = 10$ ✓, $-12 + 42 + 75 = 105$ ✓, $-1 + 0 + 6 = 5$ ✓.

Reading it as a trader

$r = m$: your products can hit every target you measure. $r = n$: no product is redundant, so every answer is unique. Real desks usually have more products than risks, and use the spare freedom to pick the cheapest or most liquid route.

In one line

$r = m$ ⇒ always possible; $r = n$ ⇒ at most one answer; both ⇒ exactly one.

8. Summary

Solving Ax = b in four steps

  1. Simplify $[A \mid b]$ to $[R \mid d]$ with the same row operations as Lesson 7. (topic 2)
  2. Zero rows: any "$0 =$ not 0" means no answer. (topic 3)
  3. One answer: free amounts $= 0$, pivot amounts $= d$. (topic 4)
  4. Every answer: pick any free amounts and read the rest, i.e. one answer + any do-nothing trade. (topic 5)
  5. $r = m$: always possible. $r = n$: at most one answer. (topic 7)

Words in this lesson

Augmented matrix $[A \mid b]$
$A$ with the target as an extra column; row operations act on the whole row.
$[R \mid d]$
The reduced form of $[A \mid b]$: $R$ on the left, the simplified target $d$ on the right.
Zero-row test
An all-zero row of $R$ must end in 0, or there is no answer.
Particular solution $x_p$
One answer; the easy one has every free amount $= 0$.
Complete solution
$x_p + x_n$ for every do-nothing trade $x_n$: every answer.
Full row rank / full column rank
$r = m$ (no zero rows) / $r = n$ (no free columns).

The other two running examples, one in each of the interesting rank cases.

Example 1: Hedging, every way to hedge

Rows: (market, currency, rates). Hedges: Nifty fut $(1, 0, 0)$, IT fut $(1, 1, 0)$, Bank Nifty fut $(1, 0, 1)$, IT-minus-Nifty spread $(0, 1, 0)$.

2 × 2: Nifty and IT futures (r = m = n)

Market and currency only, target $(10, 3)$: $\left[\begin{smallmatrix} 1 & 1 \\ 0 & 1 \end{smallmatrix}\right]x = (10, 3)$. Row 2: $y = 3$. Row 1: $x + 3 = 10$, $x = 7$. Exactly one hedge: 7 Nifty fut and 3 IT fut.

3 × 2: the same two, now with rates (r = n < m)

$\left[\begin{smallmatrix} 1 & 1 \\ 0 & 1 \\ 0 & 0 \end{smallmatrix}\right]$: the rates row is zero, so the condition is "rates target $= 0$". $(10, 3, 0)$: one hedge, $(7, 3)$. $(10, 3, 2)$: none.

3 × 4: all four hedges (r = m < n)

$$ [\,A \mid b\,] = \left[\begin{array}{cccc|c} 1 & 1 & 1 & 0 & 10 \\ 0 & 1 & 0 & 1 & 3 \\ 0 & 0 & 1 & 0 & 2 \end{array}\right] $$

  1. Rank Already a staircase with pivots in columns 1, 2, 3: $r = 3 = m$. No zero row, so every exposure can be hedged.

    Reduce Row 1 $-$ row 2: $(1, 0, 1, -1 \mid 7)$. Row 1 $-$ row 3: $(1, 0, 0, -1 \mid 5)$. $[R \mid d] = \left[\begin{smallmatrix} 1 & 0 & 0 & -1 & 5 \\ 0 & 1 & 0 & 1 & 3 \\ 0 & 0 & 1 & 0 & 2 \end{smallmatrix}\right]$.

  2. Particular Spread $= 0$: $x_p = (5, 3, 2, 0)$, the Lesson 5 hedge.

    Complete $(5, 3, 2, 0) + t(1, -1, 0, 1)$.

    Check $t = 3$ $(8, 0, 2, 3)$: market $8 + 0 + 2 + 0 = 10$ ✓, currency $0 + 0 + 0 + 3 = 3$ ✓, rates $0 + 0 + 2 + 0 = 2$ ✓. No IT futures needed at all.

Example 2: Lot sizes, every way to build a payoff

Rows: Nifty ends at 19,800 / 20,000 / 20,200 (points per lot). Products: futures $(-200, 0, 200)$, 20,000 call $(0, 0, 200)$, 20,000 put $(200, 0, 0)$, 19,900 call $(0, 100, 300)$.

2 × 2: futures and the 20,000 call, two scenarios (r = m = n)

Target $(-200, 600)$ at 19,800 and 20,200: $-200x = -200$, so $x = 1$; $200(1) + 200y = 600$, so $y = 2$. Exactly one: 1 future + 2 calls.

3 × 4: all four products (r = m < n)

Lesson 7 found rank 3 = number of scenarios, with the put free. So every payoff over these three scenarios can be built, in a line of ways. Client payoff: $b = (-200, 100, 900)$.

  1. Put = 0 19,800 row: $-200x_1 = -200 \Rightarrow x_1 = 1$. 20,000 row: $100x_4 = 100 \Rightarrow x_4 = 1$.

    20,200 row $200(1) + 200x_2 + 300(1) = 900 \Rightarrow 200x_2 = 400 \Rightarrow x_2 = 2$.

    Particular $x_p = (1, 2, 0, 1)$: 1 future, 2 × 20,000 calls, 1 × 19,900 call.

  2. Complete $(1, 2, 0, 1) + t(1, -1, 1, 0)$ (put–call parity added $t$ times).

    Check $t = 2$ $(3, 0, 2, 1)$: 19,800: $-600 + 0 + 400 + 0 = -200$ ✓. 20,000: $0 + 0 + 0 + 100 = 100$ ✓. 20,200: $600 + 0 + 0 + 300 = 900$ ✓.

    Meaning "1 fut + 2 calls + 1 × 19,900 call" and "3 fut + 2 puts + 1 × 19,900 call" are the same payoff. The desk quotes whichever is cheaper today.

Pick an example or set your own size (up to 3 rules × 5 instruments), numbers and target. The lab eliminates $[A \mid b]$, tests the zero rows, reduces to $[R \mid d]$, and writes the complete solution with full checks.
